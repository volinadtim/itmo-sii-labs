## Запуск

Python 3.12. Из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab
```

На Windows активация: `.venv\Scripts\activate`.
Откройте нужный ноутбук и выберите Restart Kernel and Run All Cells. ЛР1 и ЛР2 ожидают рабочую папку своего ноутбука (обычное поведение Jupyter); ЛР3 также поддерживает запуск из корня.

Проверенный автоматический запуск ЛР3:

```bash

.venv/bin/python scripts/verify.py
```

`requirements.txt` фиксирует окружение проверки ЛР3. Существующие ЛР1–2 перенесены без изменения кода; их сохранённые результаты относятся к прежнему окружению.

## Данные

[Real Estate Listings in Portugal — luvathoms, Kaggle](https://www.kaggle.com/datasets/luvathoms/portugal-real-estate-2024).
Файл `lab1/data/portugal_listinigs.csv` — исходный локальный снимок из ЛР1–2, имя сохранено с оригинальным написанием. Данные и исходный шаблон принадлежат своим авторам; этот репозиторий не меняет условия их использования.
SHA-256 снимка, параметры разбиения и размеры выборок записываются в `lab3/results/data_summary.json`.

В ЛР3 цена ≥500 000 € определяет класс 1. Цена и её производные не входят в признаки классификаторов. Обработка пропусков выполняется внутри CV, поэтому выборка ЛР3 отличается от старой очистки ЛР1–2. OneClassSVM использует цену в отдельной задаче поиска необычных объявлений.

## Результаты ЛР3

Проверено полное выполнение ноутбука (7 кодовых ячеек, без ошибок), сохранение всех 6 текстовых ячеек шаблона, контрольная сумма CSV, непересечение train/test и независимый пересчёт 21 метрики по сохранённым предсказаниям.

| Модель | Balanced accuracy | Precision | Recall | F1 | ROC AUC |
|---|---:|---:|---:|---:|---:|
| Константная | 0.500 | 0.000 | 0.000 | 0.000 | 0.500 |
| LogisticRegression, C=1 | 0.894 | 0.729 | 0.887 | 0.800 | 0.965 |
| SVC linear, C=1 | 0.893 | 0.725 | 0.888 | 0.798 | 0.965 |

Train: 13 832, test: 3 458. На CV включение balanced у SVC подняло recall с 0.784 до 0.911, снизив precision с 0.854 до 0.712. Это ожидаемый обмен числа пропусков дорогих объектов на ложные срабатывания. Отличия моделей на test малы; статистическое превосходство не установлено.

OneClassSVM с nu=0.05 отметил 188 из 3 458 тестовых объявлений (5.44%). Это кандидаты на проверку, не подтверждённые ошибки данных.
