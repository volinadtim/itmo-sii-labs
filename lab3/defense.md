# Защита ЛР3: часть Тима

1. **Что предсказываем?** Цена квартиры не меньше 500 тыс. €. Порог фиксирован до анализа; Price используется только для y. Вход — восемь характеристик квартиры и её расположения.
2. **Почему нет утечки?** Test отделён до обучения; медианы, масштабирование и One-Hot обучаются внутри каждого train-фолда. C выбирается по train CV. Полные дубликаты удалены до split. Разные объявления одного объекта всё ещё могут попасть в разные части — без идентификатора это ограничение.
3. **Почему новая выборка?** В ЛР1–2 удалялись неполные строки. Здесь пропуски заполняет Pipeline; размеры больше, старый test не воспроизводится.
4. **LogisticRegression.** Сигмоида от линейного score, log-loss и L2. C обратно силе регуляризации. Порог по умолчанию 0.5.
5. **SVM.** Максимальный зазор, мягкие нарушения и C. Именно SVC с linear-ядром. decision_function — score, не вероятность; граница при нуле.
6. **Дисбаланс.** balanced задаёт вес n/(2 n_k), меняя штраф ошибки каждого класса. Может повышать recall ценой precision. Числа сравнения — в svm_class_weight_cv.csv.
7. **Метрики.** Precision=TP/(TP+FP), recall=TP/(TP+FN), F1 — гармоническое среднее; balanced accuracy=(TPR+TNR)/2. ROC AUC оценивает ранжирование по score. AP суммирует precision с весами прироста recall. Высокая accuracy константной модели недостаточна.
8. **OneClassSVM.** Ищет область типичных сочетаний, не класс «дорого». Цена допустима в этой отдельной задаче. nu ограничивает ошибки обучения сверху и долю support vectors снизу; на test доля не обязана быть nu.
9. **Выброс или новизна?** На train ищем выбросы, на hold-out — необычные новые наблюдения. Для строгого novelty detection нужна проверенная чистая норма; здесь её нет.
10. **Почему не удаляем найденные аномалии?** Редкая элитная квартира может быть корректной и принадлежать интересующему классу. Без экспертной разметки нельзя утверждать, что детектор нашёл ошибки, или измерять его precision/recall.

Задание 3 не относится к этой части; его нужно объединить с решением Романа перед сдачей полной работы.
